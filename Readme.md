# Fountain of Objects Game

An interactive C# console adventure inspired by the classic Fountain of Objects challenge. Explore a dark cavern, use sound and scent to survive, find the Fountain of Objects, activate it, and return to the entrance to win.

## Overview

You begin at the cavern entrance with a bow, a small supply of arrows, and no map of the maze ahead. The only guaranteed light is at the entrance, so progress depends on the clues the cavern gives you.

As you move through the rooms, you will encounter environmental hints and dangerous creatures:

- Pits that kill instantly if you step into them.
- Maelstroms that can throw you to a different location.
- Amaroks that are deadly on contact.
- The Fountain of Objects, which must be activated before you can win.

## Features

- Three map sizes: small, medium, and large.
- Directional movement in the four cardinal directions.
- Arrow shooting with limited ammo.
- Fountain activation as the main objective.
- Sensory hints for nearby dangers and important locations.
- A built-in help command for quick command reminders.
- Total game time shown at the end of the run.

## How To Play

1. Choose a map size: `small`, `medium`, or `large`.
2. Move through the cavern using directional commands.
3. Watch for sensory clues about nearby hazards.
4. Find the Fountain of Objects and use the enable command.
5. Return to the entrance after the fountain is active to win.

## Commands

| Command | Description |
| --- | --- |
| `move north` | Move one room up. |
| `move south` | Move one room down. |
| `move west` | Move one room left. |
| `move east` | Move one room right. |
| `shoot north` | Fire an arrow one room north. |
| `shoot south` | Fire an arrow one room south. |
| `shoot west` | Fire an arrow one room west. |
| `shoot east` | Fire an arrow one room east. |
| `enable fountain` | Activate the fountain when you are standing on it. |
| `help` | Show the in-game command help. |

## Map Hints

- You see light at the entrance.
- You hear dripping water near the fountain.
- You feel a draft near a pit.
- You hear growling and groaning near a maelstrom.
- You smell a rotten stench near an amarok.


## Running The Game

Build and run the project with the .NET SDK:

1. Restore dependencies and build the project.
2. Run the console application.

If you are using Visual Studio or VS Code, you can also launch the `FountainOfObjectsGame` project directly from the solution file.

## Project Structure

- `Program.cs` starts the game.
- `Game.cs` contains the main game loop and win/lose logic.
- `Map.cs` builds the cavern and manages special room behavior.
- `Player.cs` handles player commands and actions.
- `PlayerSenseMap.cs` prints nearby environmental clues.
- `Room.cs`, `Location.cs`, and related types define the game model.

## Notes

- This game is a console experience, so all interaction happens through text input.
- The cavern layout changes based on the selected map size.
- Arrows are limited, so choose your shots carefully.
